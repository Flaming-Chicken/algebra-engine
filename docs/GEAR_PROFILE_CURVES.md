# Mathematical Foundation for Cycloid and Involute Gear Generation

## 1. Introduction to Gear Tooth Profiles

This document outlines the mathematical foundations necessary for implementing a parametric gear generation system in Rust that supports both cycloidal (including involute) and internal gears with automatic undercut avoidance.

## 2. Fundamental Gear Parameters

### 2.1 Primary Geometric Parameters

```
Key Parameters:
├── Module (m) - Scale factor defining tooth size
├── Number of Teeth (z) - Total teeth on the gear
├── Pressure Angle (α) - Angle between line of action and tangent to pitch circle
├── Addendum (ha) - Height of tooth above pitch circle
├── Dedendum (hf) - Depth of tooth below pitch circle
└── Clearance (c) - Gap between mating gear teeth
```

### 2.2 Derived Measurements

- **Pitch Diameter**: D = m × z
- **Base Circle Radius**: Rb = (D/2) × cos(α)
- **Addendum Circle Radius**: Ra = (D/2) + ha
- **Dedendum Circle Radius**: Rf = (D/2) - hf

## 3. Cycloid Gear Profile Theory

### 3.1 Epicycloidal and Hypocycloidal Curves

A cycloid curve is generated by a point on the circumference of a circle rolling without slipping along another circle (the base or pitch circle).

#### External Gears (Epicycloidal)
```
Generating Circle: Radius Rg
Base Circle: Radius Rb
Rolling Condition: Arc length = Rb × θ = Rg × φ

Parametric Equations:
x(θ) = Rb·sin(θ) + Rg·sin((Rb/Rg + 1)·θ)
y(θ) = Rb·cos(θ) - Rg·cos((Rb/Rg + 1)·θ)

Where θ is the rolling angle parameter.
```

#### Internal Gears (Hypocycloidal)
```
Parametric Equations for Internal Gear:
x(θ) = Rb·sin(θ) - Rg·sin((Rb/Rg - 1)·θ)
y(θ) = Rb·cos(θ) + Rg·cos((Rb/Rg - 1)·θ)

Note: The minus sign in the second term accounts for internal rolling.
```

### 3.2 Cycloid Gear Tooth Structure

A complete cycloid tooth consists of:

```
Tooth Profile Components:
├── Addendum Curve (Epicycloid) - Generated by exterior rolling circle
├── Dedendum Curve (Hypocycloid) - Generated by interior rolling circle
└── Root Fillet - Smooth transition at tooth root
```

## 4. Involute Gear Profile Theory

### 4.1 Definition of the Involute Curve

An involute is generated by unwinding a taut string from a base circle. The path traced by the string's endpoint forms the involute curve.

#### Parametric Equations for Involute

```
Base Circle: Radius Rb = m·z/2 · cos(α)

Involute Curve:
x(t) = Rb · (cos(t) + t·sin(t))
y(t) = Rb · (sin(t) - t·cos(t))

Where:
- t is the involute parameter (angle of unwinding)
- The tangent to the base circle at any point forms the line of action
```

### 4.2 Key Properties of Involute Gears

1. **Constant Pressure Angle**: The pressure angle remains constant throughout meshing
2. **Center Distance Insensitivity**: Center distance variations don't affect velocity ratio
3. **Smooth Engagement**: Gradual contact transition provides smooth power transmission

## 5. Undercut Analysis and Prevention

### 5.1 Understanding Undercutting

Undercut occurs when the tooth profile near the root is excessively cut away during gear generation, weakening the tooth strength.

#### Minimum Teeth to Avoid Undercut

```
For standard involute gears:
z_min = 2 / sin²(α)

With α = 20° (standard pressure angle):
z_min ≈ 17 teeth

Formula derivation from generating process limits.
```

### 5.2 Automatic Undercut Prevention Strategies

#### Strategy 1: Profile Shift (Dedendum Modification)
```
Profile Shift Coefficient (x):
x = (z - z_min) / (2 · sin²(α))

Modified Addendum and Dedendum:
ha' = ha + x·m
hf' = hf - x·m
```

#### Strategy 2: Extended Generating Circle Radius
```
For cycloid gears, adjusting the generating circle ratio:
Rg'/Rb = f(z, α)

Where optimal Rg' prevents undercut for small tooth counts.
```

## 6. Internal Gear Considerations

### 6.1 Geometric Differences from External Gears

Internal gears (rings with teeth on the inner surface) require special attention:

```
Key Considerations:
├── Opposite rolling direction of generating circle
├── Different contact ratio requirements
├── Tooth profile orientation reversal
└── Potential for interference between mating gears
```

### 6.2 Internal Gear Parametric Equations

#### Hypocycloid Profile for Internal Gears
```
Let:
- Rb = Base circle radius (inner)
- Rg = Generating circle radius  
- n = Rb/Rg ratio (internal gear ratio > 1)

Parametric equations:
x(θ) = Rb[sin(θ) - (1/n)sin((n-1)θ)]
y(θ) = Rb[cos(θ) + (1/n)cos((n-1)θ)]

Domain: θ ∈ [0, 2π·n/(n-1)] for complete tooth profile
```

## 7. Parametric Curve Approach

### 7.1 Single-Tooth Modeling Strategy

The core innovation uses a parametric curve representing a single gear tooth, which is then replicated around the gear circumference:

```
Tooth Generation Process:
1. Define parametric curve C(θ) for one half-tooth from pitch line to tip and root
2. Calculate angular span: Δθ = 2π/z (z = number of teeth)
3. Apply rotational transformations to replicate tooth around gear center
4. Mirror profile to create complete symmetrical tooth

Transformation:
T(k, θ) = Rotate(C(θ), k·Δθ) for k = 0,1,...,(z-1)
```

### 7.2 Mathematical Representation

#### Generic Parametric Form
```
Curve Definition: γ(t) = (x(t), y(t)), t ∈ [a,b]

Where for gear applications:
- x(t): Radial position function
- y(t): Tangential position function
- Parameters: m, z, α, ha, hf, generating circle radii
```

#### Discrete Replication Algorithm
```
For each tooth k (0 ≤ k < z):
1. Compute base angle: θ_k = 2πk/z
2. Apply rotation matrix R(θ_k) to parametric curve points
3. For internal gears, adjust transformation for inward-facing teeth
4. Calculate intersection points for smooth meshing

R(θ) = [[cos(θ), -sin(θ)], [sin(θ), cos(θ)]]
```

## 9. Implementation Considerations for Rust

### 9.1 Type-Safe Parameter System

Leveraging Rust's type system for gear parameter management:

```rust
// Suggested type structure
struct GearParameters {
    module: f64,          // Module size
    teeth_count: u32,     // Number of teeth
    pressure_angle: f64,  // In radians
    addendum_ratio: f64,  // ha/m coefficient
    dedendum_ratio: f64,  // hf/m coefficient

struct ToothProfile {
    curve_type: CurveType, // Cycloid or Involute
    is_internal: bool,     // Internal gear flag
    parametric_points: Vec<Point>, // Discrete curve samples
}
```

### 9.2 Numerical Precision Requirements

For accurate geometric calculations:
- Use `f64` for all dimensional parameters (15 significant digits)
- Implement tolerance checks with ε = 1e-8 for floating-point comparisons
- Apply iterative refinement for complex curve intersections
